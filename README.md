# Métodos de Investigación de Operaciones

Aplicación web, sin dependencias ni servidor, que resuelve problemas de
Investigación de Operaciones mostrando el procedimiento paso a paso, de forma
similar a como se resuelven a mano.

## Métodos incluidos
- Método gráfico
- Programación lineal (soluciones básicas)
- Método simplex (tablas)
- Penalización por M
- Transporte: Esquina Noroeste y Costo Mínimo
- Método Húngaro (asignación)

## Uso
Abre `index.html` en el navegador.

## Tecnologías
HTML, CSS y JavaScript.
